# KaitoFlow profile README

This repository powers the GitHub profile at https://github.com/kaitoflow.

## Layout

```text
assets/readme/
├── hero.svg
├── focus.svg
├── section-stack.svg
└── section-activity.svg
README.md
.github/workflows/snake.yml
```

## Snake animation

The contribution snake is generated by `.github/workflows/snake.yml` and published to the `output` branch. Enable Actions on this repository if the animation is missing.
